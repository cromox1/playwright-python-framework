That error is actually quite common. The command:

pytest --html=report.html

only works if you have installed the pytest-html plugin.

Step 1: Check if it's installed

Run:

pip show pytest-html

If you get something like:

WARNING: Package(s) not found: pytest-html

then it's not installed.

Step 2: Install it
pip install pytest-html

or, if you're using a virtual environment:

python -m pip install pytest-html

Then verify:

pip show pytest-html
Step 3: Try again
pytest --html=report.html

or

python -m pytest --html=report.html
If it still says "unrecognized arguments"

Check which pytest you're running:

pytest --version

You should see something like:

pytest 8.4.1
plugins:
    html-4.1.1

If you don't see html-... under plugins, then pytest-html isn't being loaded.

If you're using PyCharm

Sometimes PyCharm uses a different Python interpreter from your terminal.

Check:

python --version
python -m pip show pytest-html
python -m pytest --version

If python -m pytest --version lists the html plugin but pytest --version does not, then your pytest command is pointing to a different Python environment.
