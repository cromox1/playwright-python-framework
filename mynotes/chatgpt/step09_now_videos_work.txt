Excellent! 🎉 That actually demonstrates an important Playwright concept.

The difference is:

❌ This won't record video

page = browser.new_page()

because browser.new_page() creates its own temporary browser context, so it ignores the record_video_dir setting.

✅ This will record video

context = browser.new_context(
    record_video_dir="videos"
)

page = context.new_page()

because the page belongs to the configured context.

Your current flow should now look like this
browser = p.chromium.launch(headless=False)

context = browser.new_context(
    record_video_dir="videos"
)

context.tracing.start(
    screenshots=True,
    snapshots=True,
    sources=True
)

page = context.new_page()

yield page

context.tracing.stop(path=trace_name)

context.close()

browser.close()

          ├── Keep video
          └── Keep trace

This is a common enterprise practice.
