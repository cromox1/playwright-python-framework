Q = in Step 5, how to call user cred (username + password) to put into login.login(user, password)


Excellent question. In an enterprise framework, you normally create a utility function that reads the JSON file, then your test simply calls it. This is a cleaner and more maintainable approach.

Step 1. Create users.json

data/users.json

{
    "valid_user": {
        "username": "tomsmith",
        "password": "SuperSecretPassword!"
    },

    "invalid_user": {
        "username": "wronguser",
        "password": "wrongpassword"
    }
}

Notice that I use valid_user and invalid_user. Later you can easily add:

{
    "admin": {...},
    "guest": {...},
    "locked_user": {...}
}
Step 2. Create a JSON reader

utils/json_reader.py

import json
from pathlib import Path


def get_user(user_type):
    file_path = Path(__file__).parent.parent / "data" / "users.json"

    with open(file_path, "r") as file:
        users = json.load(file)

    return users[user_type]
Step 3. Read the credentials

In your test:

from utils.json_reader import get_user

user = get_user("valid_user")

Now user contains:

{
    "username": "tomsmith",
    "password": "SuperSecretPassword!"
}
Step 4. Pass it to the Page Object
login.login(
    user["username"],
    user["password"]
)

or

username = user["username"]
password = user["password"]

login.login(username, password)

I prefer the second version because it is easier to read and debug.

Complete example
from pages.login_page import LoginPage
from utils.json_reader import get_user

def test_valid_login(page):

    login = LoginPage(page)

    page.goto("https://the-internet.herokuapp.com/login")

    user = get_user("valid_user")

    username = user["username"]
    password = user["password"]

    login.login(username, password)
Step 5. Even better (Enterprise style)

Instead of returning a dictionary, return a User object.

Create

models/user.py

class User:

    def __init__(self, username, password):
        self.username = username
        self.password = password

Modify json_reader.py

import json
from pathlib import Path
from models.user import User


def get_user(user_type):

    file_path = Path(__file__).parent.parent / "data" / "users.json"

    with open(file_path) as file:
        users = json.load(file)

    user = users[user_type]

    return User(
        user["username"],
        user["password"]
    )

Then your test becomes much cleaner:

user = get_user("valid_user")

login.login(
    user.username,
    user.password
)

This is how many enterprise automation frameworks are structured.

✅ Page Object Model (POM)
