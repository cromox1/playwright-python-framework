Q = Now I feel confident with my simple playwright framework. How to properly rename the project/repo to new name (original name = playwright-python-framework), because I can find many people use the same name in github


Yes — now that your framework is working, this is a good time to rename the project before you make it public/polished on GitHub.

I would also avoid a generic name like playwright-python-framework. A recruiter seeing your repository should immediately understand that it's your QA automation framework, not just a tutorial project.

My recommended name

I'd use:

playwright-python-qa-framework

It's still clear and professional, while being more distinctive.

Other good choices:

python-playwright-automation
playwright-python-automation
playwright-qa-automation
python-playwright-test-framework
playwright-api-ui-framework
rosli-playwright-qa-framework — more personal/portfolio-oriented

For your particular project, I like:

playwright-python-qa-framework

because it clearly tells a recruiter:

Playwright + Python + QA + Framework

1. Rename the local project folder

First, close PyCharm or at least close the project.

Rename:

playwright-python-framework

to:

playwright-python-qa-framework

So your Windows path becomes something like:

C:\Users\Rosli\PyCharm_projects\playwright-python-qa-framework

Then open the renamed folder in PyCharm.

2. Rename the GitHub repository

Go to your GitHub repository.

Click:

Settings → General → Repository name

Change:

playwright-python-framework

to:

playwright-python-qa-framework

GitHub normally redirects the old repository URL to the new one, but you should still update your local Git remote.

3. Check your current remote

From your project directory:

git remote -v

You'll probably see:

origin  https://github.com/YOUR_USERNAME/playwright-python-framework.git (fetch)
origin  https://github.com/YOUR_USERNAME/playwright-python-framework.git (push)

Change it to the new repository:

git remote set-url origin https://github.com/YOUR_USERNAME/playwright-python-qa-framework.git

Then check:

git remote -v

You should now see:

origin  https://github.com/YOUR_USERNAME/playwright-python-qa-framework.git (fetch)
origin  https://github.com/YOUR_USERNAME/playwright-python-qa-framework.git (push)
4. Make sure Git still works

Run:

git status

You should see your normal project status.

Then:

git pull

If everything is correct, Git should communicate with the renamed repository.

5. Rename the project inside PyCharm

If PyCharm still displays:

playwright-python-framework

you can close the project and use:

File → Open

and select:

playwright-python-qa-framework

The actual Python code doesn't need to change just because the repository name changed.

One more thing I'd change

Since this is now becoming your QA portfolio project, I'd change the README title from something generic like:

# Playwright Python Framework

to:

# Playwright Python QA Automation Framework

And underneath:

A Python-based UI and REST API automation framework built with Playwright and PyTest.

## Key Features

- UI test automation
- REST API test automation
- Page Object Model
- PyTest fixtures
- Test data management
- Screenshot capture on failure
- Video recording on failure
- Playwright tracing on failure
- HTML test reporting
- Flask-based System Under Test (SUT)
- Git/GitHub integration
- CI/CD ready

That makes the repository look much more like a real QA engineering project rather than a collection of Playwright exercises.
