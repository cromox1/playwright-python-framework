Q = in Step 6 (Add screenshots) - how to make it will take the screenshot whenever it failed



This is actually one of the things interviewers like to hear because enterprise automation frameworks almost always capture screenshots automatically on failures.

With Playwright + PyTest, the cleanest way is to use a PyTest hook (pytest_runtest_makereport) inside conftest.py.

Option 1 (Enterprise Recommended)
Project Structure
playwright-python-framework/
│
├── conftest.py
├── screenshots/
├── tests/
│   └── test_login.py
└── pages/
Step 1

Create conftest.py

import os
import pytest
from playwright.sync_api import sync_playwright


@pytest.fixture
def page():

    with sync_playwright() as p:

        browser = p.chromium.launch(headless=False)

        page = browser.new_page()

        yield page

        browser.close()
Step 2

Still inside conftest.py

Add this hook:

import pytest


@pytest.hookimpl(hookwrapper=True)
def pytest_runtest_makereport(item, call):

    outcome = yield

    report = outcome.get_result()

    if report.when == "call" and report.failed:

        page = item.funcargs.get("page")

        if page:

            os.makedirs("screenshots", exist_ok=True)

            filename = f"screenshots/{item.name}.png"

            page.screenshot(path=filename)

            print(f"\nScreenshot saved: {filename}")
Step 3

Now purposely fail a test.

def test_login(page):

    page.goto("https://the-internet.herokuapp.com/login")

    assert "Google" in page.title()

Run

pytest

Output

FAILED test_login

Screenshot saved:
screenshots/test_login.png

You'll now have

screenshots/

    test_login.png
Option 2 (Even Better)

Include the date/time so screenshots don't overwrite each other.

from datetime import datetime

timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")

filename = f"screenshots/{item.name}_{timestamp}.png"

Example

test_login_20260806_154201.png
Option 3 (Capture the Full Page)

Instead of just the visible viewport

page.screenshot(
    path=filename,
    full_page=True
)

Very useful for long web pages.

Option 4 (Take Screenshot + HTML)

Many companies save both.

page.screenshot(path=filename)

html = page.content()

with open(f"screenshots/{item.name}.html","w",encoding="utf8") as f:
    f.write(html)

Now you'll have

screenshots/

test_login.png

test_login.html

If developers can't reproduce the issue, the HTML helps.

Option 5 (Capture Video)

Playwright supports recording video.

context = browser.new_context(
    record_video_dir="videos/"
)

If a test fails you'll have

videos/

test_login.webm

Very impressive during interviews.

Option 6 (Capture Trace)

One of Playwright's best features is tracing.

context.tracing.start(
    screenshots=True,
    snapshots=True
)

After the test

context.tracing.stop(
    path="trace.zip"
)

Open it with

playwright show-trace trace.zip

You can replay the entire execution, step by step.

One improvement I would make

Instead of saving screenshots directly under screenshots/, create subfolders by execution date. For example:

screenshots/
└── 2026-08-06/
    ├── test_login_154201.png
    ├── test_search_154523.png
    └── test_checkout_154812.png

This keeps your repository organized and is a pattern commonly used in enterprise frameworks. It's also a nice detail to mention during interviews when discussing framework design.
