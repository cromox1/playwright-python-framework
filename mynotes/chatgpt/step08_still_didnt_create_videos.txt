Q = It still didn't create '/videos' directory & the video files insode it


This usually happens for one of three reasons. Let's check them one by one.

1. Did you close the context?

Videos are only saved when the browser context is closed.

You must have:

context.close()
browser.close()

If you only have:

browser.close()

the video may never be written.

The correct order is:

yield page

context.tracing.stop(path=trace_name)

context.close()      # <-- Video is saved here

browser.close()
2. Did you create the context with record_video_dir?

It must be:

context = browser.new_context(
    record_video_dir="videos"
)

NOT

browser = p.chromium.launch(
    record_video_dir="videos"
)

record_video_dir belongs to new_context(), not launch().

3. Are you creating a Context?

It should be:

browser = p.chromium.launch()

context = browser.new_context(
    record_video_dir="videos"
)

page = context.new_page()

NOT

browser = p.chromium.launch()

page = browser.new_page()

If you use browser.new_page(), Playwright creates an internal context and you can't configure video recording for it.

Example (Working)
from playwright.sync_api import sync_playwright

with sync_playwright() as p:

    browser = p.chromium.launch(headless=False)

    context = browser.new_context(
        record_video_dir="videos"
    )

    page = context.new_page()

    page.goto("https://example.com")

    context.close()

    browser.close()

After running, Playwright should automatically create:

videos/
    xxxxxxxxx.webm
