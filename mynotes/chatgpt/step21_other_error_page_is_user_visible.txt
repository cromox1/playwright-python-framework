Yes — the error tells us exactly what is happening.

Your locator:

self.page.get_by_text(username)

is matching two elements:

1) cromox1
2) cromox1@rosli-laptop.com.my

Playwright uses strict mode, so when .is_visible() is called on a locator that matches more than one element, it fails.

Best fix for your application

Since your users.html has a table with separate columns for Username and Email, target the table cell containing the exact username.

Change your users_page.py to:

from playwright.sync_api import Page


class UsersPage:

    def __init__(self, page: Page):
        self.page = page

        self.page_title = page.get_by_role(
            "heading",
            name="User Management"
        )

    def is_loaded(self):
        return self.page_title.is_visible()

    def is_user_visible(self, username):
        return self.page.get_by_role(
            "cell",
            name=username,
            exact=True
        ).is_visible()

Then your existing test can remain:

assert users_page.is_user_visible(user_valid.username)
Why this works

Previously:

page.get_by_text("cromox1")

matches both:

cromox1
cromox1@rosli-laptop.com.my

because "cromox1" is contained inside the email address.

With:

page.get_by_role(
    "cell",
    name="cromox1",
    exact=True
)

Playwright looks specifically for a table cell whose complete text is exactly cromox1.

So it will select:

| cromox1 | cromox1@rosli-laptop.com.my |

and not the email cell.

Even better for your framework

I'd make the Users Page object use Playwright's expect() assertions:

from playwright.sync_api import Page, expect


class UsersPage:

    def __init__(self, page: Page):
        self.page = page

        self.page_title = page.get_by_role(
            "heading",
            name="User Management"
        )

    def verify_page_loaded(self):
        expect(self.page_title).to_be_visible()

    def verify_user_visible(self, username):
        expect(
            self.page.get_by_role(
                "cell",
                name=username,
                exact=True
            )
        ).to_be_visible()

Then your test becomes:

def test_valid_login(page):

    user_valid = get_user("valid_user")

    login_page = LoginPage(page)
    login_page.open()
    login_page.login(
        user_valid.username,
        user_valid.password
    )

    assert "/users" in page.url
    assert "/login" not in page.url

    users_page = UsersPage(page)

    users_page.verify_page_loaded()
    users_page.verify_user_visible(user_valid.username)

I actually prefer this version for your GitHub project because the test reads almost like a test case:

Login
  ↓
Verify Users page
  ↓
Verify user exists

rather than exposing the Playwright locator details inside the test.
