Yes. Your commented-out lines are close, but I recommend using get_by_role() or get_by_text() rather than locator("text=...").

Since your users.html contains:

<h1>User Management</h1>

you can check it like this:

def test_valid_login(page):

    user_valid = get_user('valid_user')

    login_page = LoginPage(page)
    login_page.open()
    login_page.login(user_valid.username, user_valid.password)

    assert "/users" in page.url
    assert "/login" not in page.url

    assert page.get_by_role("heading", name="User Management").is_visible()
Checking the username too

Your current users.html displays the username inside a table. You can do:

assert page.get_by_text(user_valid.username).is_visible()

So the complete test becomes:

def test_valid_login(page):

    user_valid = get_user('valid_user')

    login_page = LoginPage(page)
    login_page.open()
    login_page.login(user_valid.username, user_valid.password)

    assert "/users" in page.url
    assert "/login" not in page.url

    assert page.get_by_role(
        "heading",
        name="User Management"
    ).is_visible()

    assert page.get_by_text(
        user_valid.username
    ).is_visible()
Even better: use assertions from Playwright

For a professional Playwright project, I recommend using expect() instead of .is_visible():

from playwright.sync_api import expect


def test_valid_login(page):

    user_valid = get_user('valid_user')

    login_page = LoginPage(page)
    login_page.open()
    login_page.login(user_valid.username, user_valid.password)

    expect(page).to_have_url(
        lambda url: "/users" in url
    )

    expect(
        page.get_by_role(
            "heading",
            name="User Management"
        )
    ).to_be_visible()

    expect(
        page.get_by_text(user_valid.username)
    ).to_be_visible()

However, for the URL check, I'd actually keep your existing:

assert "/users" in page.url

because it's simple and perfectly valid.

One improvement I'd make to your framework

Since you already have a LoginPage, I'd create a UsersPage Page Object rather than putting all the User Management locators directly in the test.

For example:

pages/
├── login_page.py
└── users_page.py

users_page.py:

from playwright.sync_api import Page


class UsersPage:

    def __init__(self, page: Page):
        self.page = page
        self.page_title = page.get_by_role(
            "heading",
            name="User Management"
        )

    def is_loaded(self):
        return self.page_title.is_visible()

    def is_user_visible(self, username):
        return self.page.get_by_text(username).is_visible()

Then your test becomes very clean:

from pages.login_page import LoginPage
from pages.users_page import UsersPage


def test_valid_login(page):

    user_valid = get_user("valid_user")

    login_page = LoginPage(page)
    login_page.open()
    login_page.login(
        user_valid.username,
        user_valid.password
    )

    assert "/users" in page.url
    assert "/login" not in page.url

    users_page = UsersPage(page)

    assert users_page.is_loaded()
    assert users_page.is_user_visible(
        user_valid.username
    )

This is the approach I'd use for your GitHub project. It demonstrates proper Page Object Model separation instead of putting locators and UI knowledge directly into the test.
