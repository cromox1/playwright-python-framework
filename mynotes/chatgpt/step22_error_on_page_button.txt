Q = for button 'Login', I tried - self.page.get_by_label("Login", exact=True) ... but wrong... can you suggest what's 'get_by_*' is correct for button?


Yes. For a button, the correct Playwright locator is:

self.page.get_by_role("button", name="Login", exact=True)

So in your LoginPage:

class LoginPage:

    def __init__(self, page):

        self.page = page

        self.username = page.locator("#username")
        self.password = page.locator("#password")

        self.login_button = page.get_by_role(
            "button",
            name="Login",
            exact=True
        )

        self.login_error = page.locator("#login-error")

Then:

def login(self, username, password):

    self.username.fill(username)
    self.password.fill(password)
    self.login_button.click()
Why get_by_label() didn't work

get_by_label() is mainly for form controls associated with a label, for example:

<label for="username">Username</label>
<input id="username">

Then:

page.get_by_label("Username")

is appropriate.

For your button:

<button type="submit" id="login-button">
    Login
</button>

use:

page.get_by_role("button", name="Login")
Useful Playwright get_by_* locators
HTML element	Recommended locator
Button	get_by_role("button", name="Login")
Heading	get_by_role("heading", name="User Management")
Link	get_by_role("link", name="Logout")
Checkbox	get_by_role("checkbox", name="Remember me")
Radio button	get_by_role("radio", name="Male")
Input with label	get_by_label("Username")
Text	get_by_text("User Management")
Table cell	get_by_role("cell", name="cromox1", exact=True)
Placeholder	get_by_placeholder("Enter username")

For your project, I'd generally prioritize get_by_role() and get_by_label() over CSS/XPath selectors because they make your Page Objects more readable and closer to how a real user interacts with the application.

For your Login page, I'd therefore use:

self.username = page.get_by_label("Username")
self.password = page.get_by_label("Password")
self.login_button = page.get_by_role(
    "button",
    name="Login",
    exact=True
)

This is cleaner than:

page.locator("#username")
page.locator("#password")
page.locator("#login-button")

provided your HTML labels are correctly associated with the inputs, which yours are.
