Q = can you find a free server that I can setup for both REST API and web login


Yes. For the Playwright portfolio project you're building, I'd recommend using a hosted application where you can exercise both UI login and REST API testing, rather than maintaining two unrelated systems.

Best choice: ReqRes

ReqRes is probably the closest match to what you're looking for. It currently provides a free-to-try hosted backend with authentication, CRUD endpoints, persistent data, and request logs. It specifically documents login/register flows such as POST /api/login and POST /api/register.

ReqRes

However, there is an important distinction: ReqRes is primarily an API/backend testing service, not a full website application where you can automate a normal username/password web login page. So I wouldn't use it alone for your project.

For your GitHub project, I suggest this combination
Purpose	System
Web UI login	SauceDemo
REST API	ReqRes
Automation	Playwright + Python + PyTest
Reports	pytest-html
Failure evidence	Screenshot + Video + Trace

This gives you a realistic portfolio demonstrating both UI and API automation.

For API testing, Playwright itself supports APIRequestContext, specifically designed for sending REST requests directly from your tests.
